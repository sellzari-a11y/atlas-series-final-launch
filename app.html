Your Technical Mastery: Atlas Project Tutorials

1. Lead Funnel Connection (Mailchimp)

This is the **critical step** that turns the app into a lead-generating business tool.

**Action Required:** Paste your unique Mailchimp form action URL into the **`index.html`** file.

**Concept:** The form's `action` attribute tells the browser where to send the email data (the "long, messy URL") before the user is given the download.

2. Deployment Fix (Solving the 404 Error)

The persistent 404 error was solved by enforcing **simple, standardized filenames** on the server.

**Solution:** Always use **all-lowercase** filenames (`index.html`, `app.html`) when deploying to GitHub Pages to prevent case-sensitivity errors on the server.

**Command Concept:** Use the `window.location.href = 'app.html';` code to ensure the download link matches the simple file name.

3. Editing Content (Adding New Facts)

4. Integrating Gemini API (Notebook Analysis)

How to connect external AI to analyze the facts in your Atlas for study purposes.

**Concept:** Use the Gemini API's **`generateContent`** endpoint with a `systemInstruction` to analyze a specific fact from the Atlas and synthesize a study note.

**Action:** Set up a separate script to send the fact text and the persona instruction ("Act as a study tutor...") to the API.
